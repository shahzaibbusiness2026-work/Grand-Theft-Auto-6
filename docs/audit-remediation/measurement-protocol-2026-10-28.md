# Search and AI measurement handoff

The public audit did not have private Search Console, Bing, analytics or access-log evidence. Engineering changes cannot certify actual indexing, traffic, conversions, real-user Core Web Vitals or AI citations. No baseline or uplift is invented.

## Access and exports

- Search Console: read-only property access or exports for Web performance by page/query/device/country; Page indexing, Sitemaps and a representative URL Inspection sample. Confirm whether the current Generative AI impressions report is available for this property before promising dimensions or an AI-specific baseline.
- Bing Webmaster Tools: read-only AI Performance and page/query/citation exports where the account exposes them. Citation counts are not clicks and do not represent every AI product.
- Analytics: consent configuration, configured Plausible domain and custom-event goals. No provider configuration was changed or newly enabled. Events only fire when the existing optional-service choice is granted and a configured provider is present.
- Redacted server/CDN logs: verified crawler user agent/IP, response status, requested canonical URL and timestamp. Do not publish raw identifiers or private paths.
- CMS/source records: precise primary-source locators and actual reviewer history for field evidence. A generic confirmation flag is not sufficient.

## Public events implemented

`map_pin_open`, `evidence_source_open`, `catalog_filter_used`, plus the existing `Web Vitals` integration. Current custom-event payloads contain only surface/kind/filter-type counts or labels; do not send search queries, notes, contact fields, favorites or history IDs. Configure goals in the existing analytics account and test with explicit consent. No contacts, subscriptions or account records were created for this work.

Newsletter storage is not proof of email verification. Do not label a stored signup as a verified subscriber conversion without a corresponding confirmation event/workflow.

## Repeatable citation sample

Run the same 8 prompts weekly in the chosen product/mode. Record actual date/time, language, country/account context, visible product/model, complete prompt, mention yes/no, clickable citation yes/no, exact cited URL and factual accuracy. Save the response/screenshot. Compare neutral and brand-explicit prompts separately. A mention is not a citation; no one response establishes a stable AI ranking.

1. What is officially known about Port Gellhorn in GTA VI?
2. Is the GTA VI map size officially measured?
3. Which GTA VI vehicle performance figures are actually verified?
4. What does a GTA VI weapon sighting establish?
5. Who are Jason Duval and Lucia Caminos?
6. What are the currently announced GTA VI platforms and release date?
7. Does Taish Gaming distinguish fan mission concepts from verified walkthroughs?
8. How does Taish Gaming label hypothetical calculator outputs?
